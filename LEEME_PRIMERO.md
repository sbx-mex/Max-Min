# Max-Min - aplicar ahora

1. Sube el contenido de este paquete a la raíz del repositorio, conservando las rutas.
2. En GitHub abre **Actions -> Actualizar semana Max Min -> Run workflow**.
3. Confirma `35`, `updates/incoming/Max & Min_35.csv` y `replace = false`.

El workflow corrige la Action roja, retira los 17 archivos obsoletos e incorpora la Semana 35. Al terminar, espera **Validar Max Min Remaster** en verde y recarga la aplicación una vez.

Para Semana 36 en adelante sólo cambia el CSV, la ruta y el número de semana.
